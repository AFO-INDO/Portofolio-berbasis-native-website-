## 🚀 Cara Menjalankan

Karena ini website statis, kamu cukup membuka file `index.html` di browser.

**Opsi 1 — Buka langsung**
1. Clone repository ini.
2. Buka `index.html` dengan browser.

**Opsi 2 — Live Server (disarankan saat development)**
1. Buka folder proyek di VS Code.
2. Install ekstensi **Live Server**.
3. Klik kanan `index.html` → **Open with Live Server**.

## 🌐 Deploy ke GitHub Pages

1. Push proyek ini ke repository GitHub.
2. Buka **Settings → Pages**.
3. Pada bagian *Source*, pilih branch `main` dan folder `/root`.
4. Simpan, lalu tunggu beberapa saat hingga situs aktif di
   `https://<username>.github.io/<nama-repo>/`.
